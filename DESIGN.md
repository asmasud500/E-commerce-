# Design: Quiet boutique (storefront)

Light, warm, editorial. Admin panel keeps its own orange system.

- Ground: ivory `#faf8f5`; surfaces white; hairlines `#e9e4dc`; soft panels `#f3efe8`.
- Ink `#1b1814` for text, primary buttons, header search button and footer ground.
- Accent: admin-controlled `--store-accent`, used sparingly (kicker, hover, cart badge, dots). Text uses `--ds-cta` (darkened accent) for contrast.
- Type: `--disp` (Rubik / Hind Siliguri for Bangla), tight tracking on large headings.
- Shape: pill buttons/chips/search, 16px product-image radius, 20-24px panels.
- Product cards: borderless, 4:5 image, quiet text, slow hover zoom.
- Home: editorial hero (headline, one CTA, payment chips, stacked product photos), category chips, trust strip (fast delivery, secure payment, easy returns).
- Mobile first: 44px targets, reduced-motion respected.
